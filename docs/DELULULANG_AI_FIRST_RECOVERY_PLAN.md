**13 November 2026 · audited `ac2a16202e790657810b819e882b8d721dc0aef4` · proposed execution order.** Codex head chef, GPT‑6.1 Sol at handoff. Earlier session model and effort were not independently recorded. This is the plan requested in the owner's research commission. It takes effect as a work queue when adopted. Repository rules and recorded decisions remain in force until changed through their own process.

## Decision

**Build a CLI-first language for coding agents that run bounded data and file jobs. Hold the preview until a fresh third party can complete those jobs and distinguish a refusal, an application failure, a stop, and a completed effect.** Preserve text source, typed effects and reference capabilities, static Authority, operation-time Guard, leases, audit and host custody. Offer the interpreter and a tested WASM subset. Keep the language server and the small optional VS Code client. `delulu` already contains the compiler. Maintain one product and one set of semantic checks.

The five immediate blockers are:

1. **Verified artifacts can bypass a source rule.** A list write rejected as DL1604 from text passed `dir::verify` and `plugin verify` with colliding node IDs. A second artifact bypassed source identifier rules. `why` endorsed a forged authority summary that `plugin verify` rejected. No escape from the grant or OS jail was demonstrated. Close the verification boundary before offering untrusted artifacts.
2. **Execution can give a false account of what happened.** Report write failure after a successful file write exits as `usage`. A prestart sandbox refusal produced no promised report. `fix` can exit zero with errors, and a nonexistent test selector can pass with zero tests. A runner that retries from these signals can repeat an effect.
3. **Ordinary input and data remain missing.** `Root.args` and a standard JSON API are unavailable. A real file transformation works on both engines with a bespoke input format. Ranges, compound assignment, math, f-strings and bitwise operators have moved on since the audits. Keep the working basics and finish the data path.
4. **Package and target behavior depend on the front door.** The package directory runs, its explicit entry file misses imports, and loose `.solulu` source runs while package discovery ignores it. A non-generic higher-order function runs in the interpreter and is refused by WASM. Agents need a documented, testable supported subset and an early refusal for anything else.
5. **Install identity and deployment posture are easy to misread.** The PATH executable gives plain `1.0.0`. A clean installed build of the same version names its commit. Doctor describes its own runtime and checkout but does not compare other executables. Default custody is LEGACY and L1 containment is opt-in. Neither gives mutually distrustful processes sharing the owner's account a separate security domain.

**Next three code milestones, in order:** repair the Verified artifact boundary (P0.1), make report failure and sandbox prestart outcomes truthful (P1.1), then make `.solulu` and package invocation consistent for a mixed-source example (P1.2). Each is independently testable. Then close test and repair exit semantics, finish the minimum input/JSON task, and pass the disposable install/upgrade gate. Recover RW 2.50 from its unfinished branch after the DIR patch is integrated and if the release tasks need those methods. Do not make preview wait for user methods, tuples, interfaces, a new protocol or physical hardware.

Keep **DeluluLang** and make **`.solulu`** the new default after end-to-end support lands. Keep `.delulu` as a supported alias with no removal date. Let any contributor submit without a sponsor. Replace sponsorship at merge with independent technical review keyed to change risk, and record who actually reviewed what. Keep Apache-2.0. The owner’s test-only remote rule and release authority still apply. A usable preview candidate can be prepared there. A public testing release requires the gates below and explicit authorization for publication.

The useful security tests cross layers. Source text validation is part of the checked representation's trust boundary. `Dir::verify_checked` re-resolves, rechecks and compares facts. Authority analysis is planning data, while the Guard and actual lease govern use. For release artifacts bind exact source, dependencies, target and tool identity. **Smallest viable interop.** A separate A2A adapter handles task IDs, authentication and message validation. It calls a worker supervisor with a bounded request containing version, tenant/principal, idempotency key, exact content hash and dependency identity, selected target, deadline, byte limits and policy reference. The broker alone issues a narrower local lease tied to the run and checks revocation on use. A2A artifacts carry a typed result and provenance receipt plus content-addressed output references with bounded retrieval. MCP remains an inspection interface. Endpoint/card text, model-generated code, URLs and tool output are all untrusted. Prevent SSRF through approved endpoint registry and pinned identity, validate payload size/depth/type and archive paths, sanitize logs, retain audience-bound auth, and recheck static facts plus actual grants at execution. Do not treat artifact signatures, agent cards or task IDs as permission. Audit task ID, build/content hash, grant lineage and performed/refused effects, without embedding bearer tokens. A retry reuses an idempotency key under the same authenticated principal and content. Cache only immutable results. If storage or an external service cannot deduplicate a committed effect, return an explicit indeterminate status and stop automatic retry.

**First interop demo, after local alpha.** Two independent processes use distinct sandbox test identities. One sends a typed telemetry-summary task to a local A2A server with an immutable fixture. The worker uses read-only access to that fixture and one result sink. Assert exact artifact hash and expected summary, no access to a sibling file, reject wrong audience or cross-principal status/cancel, duplicate requests return one run, conflicting content under the same key refuses, deadline/revocation stops before next effect, and replay after expiry is denied. Kill worker and adapter after the first committed write and check one side effect with a durable receipt or honest indeterminate status. Feed untrusted agent instructions and a path traversal archive and assert neither changes policy or writes. No network federation, real actuation or universal agent protocol is needed for this test.

Another agent should choose DeluluLang if these tasks become easier to review and safer to rerun because the required authority is inspectable from code and then enforced at use. Until demonstrated, Python/TypeScript with MCP/A2A and equivalent sandboxing is the usability baseline, and Rust remains a good host adapter language. ROS/V2X, flight and real-time controls belong behind independently engineered host adapters and interlocks. Simulation can exercise stale frames, duplicate sequence IDs and failure transitions. A scoped grant cannot establish correct intent, reaction deadlines or operational safety.
